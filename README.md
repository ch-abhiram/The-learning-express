# The Learning Express

A simple educational newspaper-reading website that transforms selected *Indian Express* articles into accessible explanations for students in Classes 8–10.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Development

Install dependencies:

```bash
bun install
```

Run locally:

```bash
bun run dev
```

Build:

```bash
bun run build
```

## Deployment

The project is automatically deployed to GitHub Pages via GitHub Actions whenever changes are pushed to the `main` branch.
